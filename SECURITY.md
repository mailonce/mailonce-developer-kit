# Security

Please do not report security vulnerabilities in a public GitHub issue.

If you believe you found a security issue affecting MailOnce or one of the examples in this repository, email:

**support@mailonce.org**

Include enough detail to reproduce the issue safely, but do not send real user credentials, session secrets, private inbox tokens, or unrelated personal data.

This public repository contains developer examples only. The MailOnce production application and infrastructure are maintained separately.
